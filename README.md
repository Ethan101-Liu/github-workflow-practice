## 怎样确认成就是否到账？

打开个人主页，在 Achievements 栏点击徽章可以查看详情。核对 Pull Request 时，可以打开 Conversation 标签确认合并人和目标分支，再检查评审记录。PR 显示 Merged 只能证明合并已完成，徽章是否公开显示需要单独核对。
